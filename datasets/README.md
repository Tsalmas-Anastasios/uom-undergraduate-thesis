# Research Datasets

The complete datasets used for the empirical analysis are not stored
directly in this Git repository because of their size.

## Files

### github_pull_request_sonarqube_results_202605142154.csv

Raw SonarQube analysis dataset generated from the collected GitHub
Pull Requests.

Size: approximately 3.56 GB.

### github_pull_request_sonarqube_results_pairs.csv

Dataset containing the generated base/closed Pull Request pairs used
during the preprocessing and investigation stage.

Size: approximately 1.77 GB.
